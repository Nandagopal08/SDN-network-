# Ryu controller environment - Python 3.9 virtualenv (created by scripts/setup_ubuntu.sh).
#
# Why pinned / why Python 3.9:
#   ryu 4.34 (final upstream release) needs eventlet 0.30.2 (it imports
#   eventlet.wsgi.ALREADY_HANDLED, removed in later eventlet releases), and
#   eventlet 0.30.2 crashes on Python >= 3.10 ("cannot set 'is_timeout'
#   attribute of immutable type 'TimeoutError'").  Ubuntu 22.04 ships 3.10 and
#   24.04 ships 3.12, so the venv uses a uv-managed Python 3.9.
#
# Install order matters: ryu is an sdist built with pbr, so first
#   pip install setuptools==58.2.0 wheel pbr==7.1.3
# then
#   pip install --no-build-isolation -r requirements-ryu.txt
#
# This set was resolved and smoke-tested on Ubuntu 22.04 aarch64 (2026-10-27).
